# AGENTS.md — working notes for AI coding agents in this repository

Read this before changing code. Every claim below was verified against the tree; if you
find one that is no longer true, fix this file in the same commit.

## What this project is

**Interactive Roadmaps** — a zero-backend React 19 + Vite + TypeScript SPA that turns
articles/roadmaps into interactive engineering courses. No server, no database, no accounts:
settings and learner progress live in `localStorage`, generated courses in IndexedDB
(Dexie), and AI calls go straight from the browser to OpenAI / Groq / Ollama.

Design philosophy worth preserving: **no custom CLI scripts, no build complexity, works
offline.** Propose a Vitest-powered solution before proposing a new script.

## Non-obvious invariants (violating these causes silent breakage)

1. **Widget type keys are hyphenated**: `sandbox`, `mutator`, `trade-off`,
   `context-diagram`, `socratic-chat`. Specs and docs repeatedly write `context_diagram`,
   `trade_off`, `node_graph`. Underscore forms match **no** schema literal or registry
   entry, so the widget silently never renders — and neither `tsc` nor the validators catch
   it. `lessonParser` normalizes underscores on *input* only. If a spec says underscores,
   implement hyphens and note it.
2. **`src/engine/contextManager.ts` is not the staged-pipeline context.** It trims chat
   history for `aiService`. The S3 stage tracker is `src/engine/stageContext.ts` (the spec's
   filename was taken). Do not "fix" this by overwriting it.
3. **There is no `lessonLength` field** anywhere. Lesson size is
   `metadata.estimatedMinutes` (1–60); word budgets derive from it at 130 words/minute.
4. **`docs/` is gitignored** (bare `docs` entry in `.gitignore`), including the agent
   authoring contract `docs/MCP_INSTRUCTIONS.md`, which `README.md` references. New files
   there need `git add -f`. A plain `!docs/file` negation cannot work — the parent directory
   is excluded.
5. **Validation entry point is a test, not a script.** `npm run validate:lesson` does not
   exist and cannot: plain Node cannot resolve this project's extensionless TS imports or
   the `@` alias. Use `src/engine/contentValidation.test.ts`.
6. **Staged generation is opt-in** (`settings.useStagedGeneration`, off by default). With it
   off, generation is the original single-call path; tier-based widget gating only applies
   inside the staged pipeline.
7. **Widget ids are generated by the parser** as `${lessonId}-widget-${n}`, and markdown
   must reference them (`<widget id="..." />` for static content, `:::widget <type>` blocks
   for AI-authored). A marker with no matching widget renders as dead text; a widget with no
   marker is never shown. `contentValidation.test.ts` checks both directions.
8. **`:::widget` syntax is whitespace-delimited** — `:::widget context-diagram`, never
   `:::widget{type="..."}`. The braced form matches no regex and is dropped in silence.
9. **Progress keys are shared.** Generated courses also use ids like `lesson-1`, so
   `CustomCourse` namespaces them as `custom:${courseId}:${lessonId}`; reusing raw ids would
   cross-mark static curriculum lessons complete.
10. **AI must always be mocked** in tests (`vi.mock('@/engine/aiService', ...)`), and every
    generation entry point takes `settings` as a parameter — nothing in `src/engine` should
    read `useSettingsStore` except `diagramGenerator`, which falls back to it deliberately.

## House conventions

- Match the surrounding file; the codebase is consistent about typed functional components,
  `cn()` for classes, semantic Tailwind tokens (`bg-muted`, `text-foreground`) over raw
  palette colors.
- Comments: explain *why*, not what. Several files document deliberate spec departures at the
  top — keep that habit.
- Never mutate caller data (`fixCommonDiagramErrors`, `calculateDiagramLayout` return copies).
- Determinism matters in layout code: use code-point comparison, not `localeCompare`, which
  is locale/ICU dependent.
- React 19 supports `inert` as a prop — used for the closed mobile drawer.
- Child effects run before parent effects: `Layout` deliberately sets **no** `document.title`,
  each page owns its head via `usePageMeta`.

## Testing notes

- `environment: 'jsdom'` for all tests, setup in `src/test/setup.ts`, include
  `src/**/*.{test,spec}.{ts,tsx}`.
- jsdom has **no IndexedDB** — mock `./localCourses` (see `generationHistory.test.ts`) rather
  than relying on a real DB.
- React Flow renders nodes inside a `visibility: hidden` measured container in jsdom, so
  `getByRole` cannot see them; query by the published `data-node-type` / `data-icon`
  attributes instead (see `ContextDiagram.test.tsx`).
- Mock `window.matchMedia` per test and reset it in `beforeEach`; a leaked mobile mock makes
  desktop assertions depend on file order.
- Guard every async state write against unmount (`aliveRef` pattern in the pages).

## Known-broken baseline (do not blame your change, but do not extend)

- `npx eslint .` is red repo-wide (~67 errors): mostly `no-explicit-any` in older tests and
  `react-hooks/set-state-in-effect` in `SettingsModal` and elsewhere. Lint **your** files
  individually and compare against that baseline instead of claiming lint is clean.
- `src/engine/generatorSchema.ts:738` throws without a `cause` (pre-existing).
- `index.html` still ships `noindex, nofollow`; `public/robots.txt` matches it. Flipping to
  public indexing is a human decision, not an agent cleanup.
- Per-route SEO is limited by client-only rendering; real indexing needs build-time
  prerendering (see `docs/ARCHITECTURE.md`).

## Working tree hazards

- The user runs **more than one agent session against this same worktree**, and another
  session can commit or move files mid-task. Immediately before committing, re-check
  `git status --short` and `git log --oneline -3`, and confirm your edits survived by
  grepping for a signature identifier rather than trusting a diffstat.
- Commit locally. "Commit your changes" does **not** authorize pushing to `origin`.
- Do not revert or restage work you did not author; surface it instead.
- File writes report LF→CRLF warnings; harmless here.
